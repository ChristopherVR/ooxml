# 本地化

编辑器界面支持五种语言，可通过 `locale` 属性、对象属性或绑定属性进行选择：

| 值      | 语言         |
| ------- | ------------ |
| `en`    | 英语（默认） |
| `fr`    | 法语         |
| `de`    | 德语         |
| `es`    | 西班牙语     |
| `zh-CN` | 简体中文     |

任何 BCP 47 标签都会映射到其中之一（`normalizeEditorLocale`）：`de-DE` 变为 `de`，`es-MX` 变为 `es`，`zh-Hans` 变为 `zh-CN`。繁体中文（`zh-TW`、`zh-Hant`）和不受支持的语言会回退为英语。

```ts
editor.locale = navigator.language;
```

本地化仅涵盖界面文本：功能区标签、对话框、菜单、状态栏和消息。它从不翻译工作簿内容。公式中的函数名保持英文（与文件中存储的一致），数字和日期格式则按工作簿的定义显示，而不是按界面语言显示。

演示通过其 URL 中的 `?locale=` 参数指定语言，并提供语言选择器。
