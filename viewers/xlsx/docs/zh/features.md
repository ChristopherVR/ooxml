# 功能与限制

::: info 2026-10-26
2026-10-26 更新：共享图表高级格式控件、ChartEx 编辑以及 SmartArt 样式、颜色和解释式预览已经实现。下方译文仍保留部分较早的限制说明。当前范围与剩余限制请参阅[英文功能页](../features.md)；[交付证据](https://github.com/ChristopherVR/ooxml/blob/main/docs/office-shared-parity-delivery.md)区分实现情况与原生 Office 验证。
:::

对于允许的本地工作簿，ChartEx 支持共享数据表、系列类型选项、坐标轴和数据点标签控件，包括结构编辑和安全扩展工作簿。共享格式窗格支持图案填充、效果以及文本和形状的三维格式。不支持的外部数据和存在歧义的层级来源会被拒绝；仅适用于经典图表的系列和次坐标轴控件会隐藏。跨六种绑定的十二个 Word/Excel 浏览器案例和部分 Office 16 验证仅覆盖有限路径，不代表原生布局一致。

编辑器依据[稳定性策略](https://github.com/ChristopherVR/ooxml/blob/main/docs/stability.md)属于稳定版。它**不等同于 Microsoft Excel**：模型未覆盖的内容在保存时会被保留或予以报告，详见[保留保证](/preservation)。本页列出编辑器能够处理和无法处理的内容；当工作簿包含不受支持的内容时，编辑器会报告出来（`workbook-warning`），而不是隐藏。

[当前的对等状态与证据](https://github.com/ChristopherVR/ooxml/blob/main/docs/xlsx-parity-status.md)总结了已实现的工作、与原生 Excel 的对比以及剩余的差距。编辑并保存后哪些内容会保留、哪些会被丢弃或报告，见[支持的功能与保留保证](/preservation)。

## 网格与格式

- 单元格值、带富文本片段的共享字符串、布尔值、错误和日期（1900 和 1904 日期系统）。
- 字体、填充（纯色、图案，渐变为近似）、边框、对齐、自动换行、缩进、旋转。
- 数字格式：分节、条件、颜色、日期和时间、分数、科学计数、文本。放不进列宽的 General 数字会减少小数位或切换为科学计数法，其他数字显示为 `###`，均按浏览器的字体测量。
- 编辑后，行高会随换行或放大的文本调整，除非该行设置了自定义高度。
- 合并单元格、列宽和行高、隐藏的行和列、冻结窗格、缩放、网格线。
- 条件格式：单元格规则、文本规则、“发生日期”（今天、最近 7 天、本月等）、前几项和后几项、高于平均值、重复值、色阶、数据条、图标集，并提供可编辑、重新排序和删除规则的规则管理器。
- 数据验证，网格中提供列表下拉。
- 批注（显示、编辑；串联回复显示为注释）、超链接。

## 公式

计算引擎位于 `ooxml-core`，每次编辑后会重新计算依赖单元格。其函数目录包含 497 个函数（2026-10-15 根据 `FUNCTION_CATALOG` 统计），涵盖数学和三角函数、统计（包括反分布以及 `LINEST`、`LOGEST`、`TREND` 和 `GROWTH` 系列）、逻辑、文本（包括 `REGEXTEST`、`REGEXEXTRACT` 和 `REGEXREPLACE`）、日期、查找（包括 `XLOOKUP` 以及 `FILTER`、`SORT`、`UNIQUE` 和 `SEQUENCE` 等动态数组）、信息、财务（包括债券、息票、不规则周期证券函数（`ODDFPRICE`、`ODDFYIELD`、`ODDLPRICE`、`ODDLYIELD`）、贴现证券和国库券函数，以及 `AMORDEGRC`、`VDB` 和 `XIRR`）、工程（包括 `COMPLEX`、`IM` 系列函数、`CONVERT` 和 `BESSEL` 函数）和数据库（`DSUM`、`DCOUNT`、`DGET` 等）。“插入函数”按类别列出这些函数。

并非所有 Excel 函数都存在：未知函数会显示 `#NAME?`。以下函数尚未实现：`ASC`、`DBCS`、`JIS`、`PHONETIC`、`INFO` 和 `WEBSERVICE`。`GETPIVOTDATA` 从缓存记录中读取本编辑器的数据透视表（工作表区域透视表），无法解析的内容返回 `#REF!`。`GROUPBY` 和 `PIVOTBY` 是子集：仅一个聚合函数（`SUM` 或 `PERCENTOF` 等函数名，或 `LAMBDA`），仅总计（总计深度 0、1 或 -1，无分类汇总），字段标题 0、1 或 3，不支持函数数组，输出为重复行标签的扁平分组；`PIVOTBY` 仅接受一个列字段。`TRIMRANGE` 以数组而非引用返回裁剪后的值。`BESSELJ(1.9,2)` 返回精确值 0.3299257277，与 Microsoft 文档中的 0.329925829 不同（Excel 本身在此处约有 1e-7 的偏差）。不规则周期证券函数使用准息票方法，并能重现 Microsoft 的示例；较长的不规则首期尚未与 Excel 核对。外部工作簿引用会保留，但不会解析。

循环引用会被报告，并保持为 0，除非开启了迭代计算。在“文件 > 选项 > 公式”中开启（启用迭代计算，并设置最多迭代次数和最大误差）；该设置随工作簿保存（`calcPr iterate`、`iterateCount`、`iterateDelta`）。之后循环组最多重新计算到最大迭代次数，一旦没有单元格的变化超过最大误差即停止。开启或关闭它不是一个撤销步骤。

计算可以在自动和手动之间切换（“公式 > 计算选项”，或“文件 > 选项”）；该模式随工作簿保存。“立即计算”（F9）和“计算工作表”（Shift+F9）可按需重新计算。“显示公式”（Ctrl+\`）显示公式文本而不是结果。

## 编辑

在单元格中输入（值和公式）、编辑栏和名称框、用 Ctrl+; 和 Ctrl+Shift+; 输入当前日期和时间、填充、复制和粘贴（系统剪贴板支持文本和 HTML；多个区域共享行或列时会一起复制，与 Excel 相同）、插入和删除行、列和单元格、排序、筛选、删除重复项、查找和替换、工作表管理（添加、重命名、移动、隐藏、着色；新工作表以界面语言命名，例如德语中的 `Tabelle2`）、内置单元格样式、表格（样式选项、标题行和汇总行、调整大小、转换为区域）、行和列的分级显示组、页面设置和打印选项（网格线、标题、居中）、带有有意义步骤名称的撤销和重做。公式引用会随结构性编辑而更新。

“数据 > 预测 > 模拟分析”有三种工具。**单变量求解**更改一个输入单元格，直到公式单元格达到目标值，并迭代重新计算引擎（最多为工作簿的最大迭代次数，默认 100，直到处于最大误差内，默认 0.001）；“单变量求解状态”对话框点击“确定”保留结果，点击“取消”则还原，整个运行是一个撤销步骤。**数据表**将所选区域转换为单变量或双变量的 `{=TABLE(行输入, 列输入)}` 表：每次计算后，通过把表头的值代入输入单元格来重新计算结果（真正的输入单元格从不更改），该表以 `<f t="dataTable">` 读取和保存，编辑其中一部分会被拒绝（“Cannot change part of a data table.”；选中整个表并清除即可将其删除）。**方案管理器**可添加、编辑、删除和显示方案（每个方案最多 32 个可变单元格，带注释和保护标志），保存为工作表的 `<scenarios>` 元素。**预测工作表**（数据 > 预测）打开一个对话框，可设置时间轴和数值区域、预测终点、置信区间、季节性（自动或手动）、缺失点的填充方式和重复项的汇总方式、可选统计信息以及折线图或柱形图，并在新工作表上使用 `FORECAST.ETS` 和 `FORECAST.ETS.CONFINT` 公式生成预测；其数值与 Excel 的差异列于 [functions.md](/functions)。方案和数据表会随行列的插入和删除而移动。方案管理器的**摘要**会在方案工作表之前生成标准的“方案摘要”工作表（仅含数值，版式和样式与 Excel 16 写入的一致，包含每个方案的可变单元格和您指定的结果单元格），**合并**则会追加本工作簿中另一张工作表的方案（重名时变为 `<名称> <yyyy-mm-dd>`，与 Excel 一致）。未实现：方案的数据透视表报告、从其他工作簿合并、单变量求解的单步和暂停，以及位于输入单元格所在工作表之外的数据表。

工作表和工作簿结构保护可以带有密码。它用于防止意外编辑，而不是安全措施。编辑器既读取并校验 Excel 旧版的 16 位哈希，也读取并校验较新的 SHA-512 哈希（还有 SHA-1、SHA-256 和 SHA-384），因此无论文件携带哪种哈希，“撤销工作表保护”和“撤销工作簿保护”都会要求输入密码。在编辑器中设置的密码以旧版哈希写入。如果某个保护使用了核心无法计算的摘要，则任何密码都无法将其解锁。

图片和图表通过单击来选中：可用鼠标移动和调整大小，用方向键微调，用 Delete 删除；选中图表时会显示“图表设计”选项卡。

## 图表与 SmartArt

常见图表系列（柱形、条形、折线、面积、饼图、圆环图、散点图、气泡图、股价图（最高-最低-收盘和开盘-最高-最低-收盘）和雷达图）、带次坐标轴的条形图/折线图组合，以及瀑布图、直方图、树状图和旭日图（只读，来自其 ChartEx 部分）根据实时值渲染为 SVG。成交量股价图组合和曲面图显示为带标签的框架。

**插入 > 图表** 打开与 Word 和 PowerPoint 共用的图表选择器。每个图表都基于其解析后的图表模型（`ChartSpace`，即 `ooxml-core/chart` 中的共享模型）进行编辑：

- **图表设计选项卡：** 图表样式、更改颜色和图表布局（柱形图、条形图、折线图和面积图的快速布局 1 至 11）库、图表标题和图例、类型、系列选项以及删除。这些库是共享的，因此在各产品中外观一致。
- **格式窗格：** 停靠的共享图表格式窗格。可编辑图表的边框和轮廓、坐标轴（边界、单位、刻度、交叉、刻度线、标签、数字格式）、网格线、数据标签、图例和系列选项。系列填充和图表区填充可通过“系列选项”中的命令打开同一窗格。
- 更改图表类型时会保留格式：标题、图例、坐标轴和填充都会延续到新类型。
- 若某图表部件的内容超出模型可表示的范围（例如曲面图的带格式等顶层以下的细节），则绝不会根据模型重写。其图表命令和格式窗格将被禁用，工作簿会给出警告，并按原始字节保存，仅修补已移动的引用。

未提供：格式窗格中的效果、三维格式、文本选项、图案和图片填充、趋势线、误差线、标记和坐标轴标题（目前尚无共享的写入意图）。图表样式是经过挑选的重新着色预设，因此无法创建样式定义（`styleN.xml`）；曲面图不会被绘制。导入的图表格式、受支持的阴影和渐变、坐标轴可见性、继承的字体、混合格式的标题片段、自动标题换行以及标题段落间距均支持渲染和保留。导入的手动标题位置和覆盖会被渲染，标题、绘图区和图例的布局 XML 在更改图表类型时保留。图表文本的精确测量、换行、位置和光栅保真度仍不完整，许多坐标轴、标签和效果控件也是如此。原生 Excel 检查涵盖特定的编辑和导出路径（`src/core/scripts/xlsx-excel-acceptance.ps1` 在桌面版 Excel 中打开保存的工作簿）；它们不代表原生版式的一致性。

**插入 > SmartArt** 打开共享的版式选择器（35 种版式）。选中图形后会显示“SmartArt 设计”选项卡（在后面、前面、上方和下方添加形状、升级、降级、上移、下移、文本窗格和更改布局，与 Word 相同的命令）。文本窗格会在网格旁边打开，双击图形也会打开它。每次节点编辑以及文本窗格中的每次击键，都是一个可撤销的步骤。插入、编辑或保存时没有缓存绘图的图形会以近似版式绘制，并标记为与 Excel 不一致。Excel 在打开文件时会重新计算版式，已保存的文件可在桌面版 Excel 中无需修复地打开（`src/core/scripts/xlsx/smartart-excel-acceptance.ps1`）。SmartArt 样式、更改颜色、按形状的格式设置以及文本窗格中的富文本尚未实现。

## 迷你图

Excel 2010 的迷你图绘制在其所在单元格中，位于单元格文本之后：折线（带标记以及最高点、最低点、首点、尾点和负点）、柱形和盈亏。绘制遵循该组关于空单元格（间隙、零或连接）、纵坐标轴（每个迷你图、整个组或自定义范围）、零值处的横坐标轴、日期轴、从右到左绘制、隐藏单元格以及主题色或 RGB 颜色的设置。当其数据区域中的单元格发生变化时，迷你图会重绘，并随其单元格调整大小。迷你图的 XML 按加载时的原样保存，插入或删除行和列时，迷你图会随其单元格移动。

“插入 > 迷你图”根据数据区域和位置区域创建折线、柱形和盈亏组。纵向的位置区域将数据行对应到各个迷你图；横向的位置区域则对应数据列。选中宿主单元格并选择“迷你图设置”，即可更改整个组的类型、标记、系列和负点颜色、线条粗细、空单元格和隐藏单元格的处理、坐标轴可见性、方向，以及各自、共享或自定义的纵向范围。“清除所选迷你图”会移除所选宿主；“清除迷你图组”会移除其整个组。这些更改支持撤销以及保存和加载。

不提供样式图库、分组和取消分组。日期轴可在迷你图设置中打开或关闭。不会匹配 Excel 的精确像素输出（标记大小、柱间距和线条抗锯齿），数据区域中的非数值单元格按空处理。

核心的往返测试和 Excel 验收检查位于 `ooxml` 仓库。如果某个工作簿渲染或保存有误，请提交 issue，若可以分享文件，请附上该文件。

打开工作簿时会报告数字签名，保存时会将其移除。编辑器不会对文件签名。超链接遵循共享核心的策略；只有网页和电子邮件链接会在外部打开。
