# 支持的功能与保留保证

本页是 [稳定性策略](https://github.com/ChristopherVR/ooxml/blob/main/docs/stability.md)
对一个稳定版产品要求的书面清单。它说明 Excel 编辑器建模和编辑了哪些内容，在编辑和保存过程中原样保留了哪些内容，以及丢弃或拒绝了哪些内容（并附上它显示的消息）。
[功能与限制](/zh/features)描述面向用户的行为，[函数列表](/functions)描述计算引擎。本页不声称编辑器与 Microsoft Excel 完全一致，也不声称保存的文件与源文件完全相同：下面的承诺范围更窄。

## 保证 {#the-guarantee}

编辑器未建模的内容（未知元素、扩展列表、部件、关系、自定义 XML 等）在打开工作簿、编辑并保存之后仍然保留，否则编辑器会报告它无法保留该内容。静默丢失属于缺陷，会在补丁版本中修复。

“保留”是指 XML 或字节原样返回，并位于有效的位置。它并不意味着整个包完全相同：编辑器从其模型重新生成的部件（如下所列）会被重写，而 Excel 在下次保存时可以再次重写它们。

## 已建模并可编辑的内容 {#what-is-modelled-and-edited}

这些内容被读取到模型中，通过编辑会话进行编辑，并从模型写回。其中模型未包含的属性和子元素，在表格所示的情况下会被保留。

| 范围       | 已建模并从模型写回                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 单元格     | 值、公式（共享公式会被展开）、数组公式和动态数组公式及其元数据、数据表公式、富文本字符串、错误值、两种日期系统下的日期。                                 |
| 行与列     | 高度、宽度、隐藏、大纲级别、折叠、行和列格式、粗的顶部/底部行提示。                                                                                      |
| 格式       | 字体、填充、边框、数字格式、对齐、保护、命名单元格样式、差异格式。                                                                                       |
| 工作表     | 合并单元格、冻结窗格、视图、缩放、网格线、工作表标签颜色、状态（可见、隐藏、非常隐藏）、带密码哈希的保护、页面设置、打印选项、打印区域、页眉和页脚。     |
| 规则与列表 | 条件格式（受支持的规则类型）、数据验证、超链接、自动筛选、带筛选和汇总行的表格、已定义名称。                                                             |
| 批注       | 备注、带作者信息的串联批注。                                                                                                                             |
| 图形       | 图表（通过共享图表模型；模型无法容纳的图表会按原样保留）、图片、它能识别的形状、SmartArt（缓存的绘图会重新生成，源数据被保留）、迷你图、切片器和时间线。 |
| 分析       | 编辑器支持的工作表区域数据透视表、模拟运算数据表、方案管理器中的方案。                                                                                   |
| 工作簿     | 工作表顺序和名称、活动工作表、已定义名称（包括宏名和函数名的属性）、计算设置、工作簿保护、日期系统、主题配色和字体。                                     |
| 属性       | 核心、扩展和自定义文档属性。                                                                                                                             |

## 编辑和保存过程中原样保留的内容 {#what-is-kept-unchanged-through-an-edit-and-a-save}

串联批注的编辑会保留作者、创建日期、消息标识、人员账户记录、已解决状态以及未知的批注标记。导入的提及会跟随其未更改标签周围插入或删除的文本；更改标签会移除该提及。复制串联批注时会为其分配新的消息和提及标识，同时保留其引用的人员。编辑器可以解决和重新打开串联批注，但无法创建新的 @提及。

当没有任何模型内容会重新生成某个部件时，写入程序会逐字节复制源包中的该部件（连同其关系以及它们所引用的每个部件）。其来源是 `src/core/xlsx/write/package-writer.ts` 中的 `PackageWriter.carry`，由 `saveXlsx`（`src/core/xlsx/write/save.ts`）和 `writeWorksheet`（`src/core/xlsx/write/worksheet.ts`）驱动。

| 保留的内容                                 | 方式                                                                                                                                                                                                                                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.xlsm` 的 VBA 项目（`xl/vbaProject.bin`） | 连同其关系和启用宏的内容类型一起保留。宏从不运行。将工作簿另存为 `.xlsx` 会移除该项目，因为该格式无法容纳它。                                                                                                                                                                                     |
| 自定义 XML（`customXml/*`）及其属性部件    | 连同工作簿关系以及各部件之间的关系一起保留。                                                                                                                                                                                                                                                      |
| 外部链接（`xl/externalLinks/*`）           | 连同其（外部）关系目标一起保留；`externalReferences` 元素保留在 `workbook.xml` 中。链接不会被更新（加载时会报告）。                                                                                                                                                                               |
| 连接、查询表以及其他工作簿部件             | 写入程序未重新生成的任何工作簿关系，无论其类型如何，都会连同其目标部件一起保留。                                                                                                                                                                                                                  |
| 打印机设置、控件属性、自定义属性           | 写入程序未重新生成的工作表关系，会连同其目标部件一起保留（`printerSettings`、`ctrlProps`、`customProperty`、嵌入对象、图片）。                                                                                                                                                                    |
| 模型未表示的工作表元素                     | `sheetCalcPr`、`phoneticPr`、`rowBreaks`、`colBreaks`、`customProperties`、`cellWatches`、`ignoredErrors`、`smartTags`、`oleObjects`、`controls`、`picture`、`webPublishItems`、`extLst` 以及架构中的其他元素，都会以 XML 保留，并按架构顺序写回。`extLst` 中未知的扩展条目保持原样。             |
| 已建模工作表元素的源属性                   | 当已建模的部件未发生更改时，`sheetPr`、`sheetViews`、`sheetFormatPr`、`sheetProtection`、`autoFilter`、`pageMargins`、`pageSetup` 和 `headerFooter` 会保留模型未包含的属性。                                                                                                                      |
| 模型未表示的工作簿元素                     | `fileVersion`、`fileSharing`、`functionGroups`、`externalReferences`、`oleSize`、`customWorkbookViews`、`smartTagPr`、`smartTagTypes`、`webPublishing`、`fileRecoveryPr`、`webPublishObjects`、`extLst`、`bookViews` 中的每个窗口，以及 `workbookPr`、`workbookView` 和 `calcPr` 中未建模的属性。 |
| 图表工作表、对话框工作表、宏工作表         | 整体保留（显示为空工作表，并在加载时报告）；它们的引用会跟随工作表的重命名和删除。                                                                                                                                                                                                                |
| 不受支持的数据透视表部件、数据透视表缓存   | 连同其关系一起保留；缓存定义会跟随工作表的重命名。                                                                                                                                                                                                                                                |
| 编辑器未修改的绘图和图表                   | 未编辑对象的绘图、图表、样式、颜色和媒体部件会逐字节保留。                                                                                                                                                                                                                                        |
| 主题                                       | 除非主题配色被更改，否则予以保留。                                                                                                                                                                                                                                                                |

`src/core/xlsx/write/preservation.test.ts` 检查本表的前几行：它构建一个包含 VBA 项目、自定义 XML、带外部目标的外部链接、连接部件、打印机设置、控件属性部件、未知关系、工作簿和工作表中未知 `extLst` 条目、上文列出的每个工作表元素以及第二个工作簿窗口的包，编辑一个单元格，保存，并断言每个部件都是字节相同的、每个关系和内容类型都存在，且每个 XML 片段都按架构顺序恢复。对结果的第二次保存是稳定的。`save.test.ts` 对 Excel 和 openpyxl 自己生成的文件执行同样的检查。

## 被丢弃的内容及原因 {#what-is-dropped-and-why}

| 被丢弃的内容                                                   | 原因                                                                                                                                                                       |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `xl/calcChain.xml`                                             | 由 Excel 重建；工作簿以 `fullCalcOnLoad` 保存，因此每个值在打开时都会重新计算。                                                                                            |
| 数字签名（来源、签名部件及其关系）                             | 任何更改都会使其失效。加载时会报告：“The workbook is digitally signed ... saving removes it”（该工作簿已数字签名……保存时将移除签名）。Excel 也会丢弃它们。                 |
| 以 `.xlsx` 保存时的 VBA 项目                                   | 该格式无法容纳它。`.xlsm` 格式则按加载时的原样保留。                                                                                                                       |
| `x15ac:absPath`（文件上次保存的位置）和 `xr:revisionPtr`       | 供 Excel 使用的编写提示，由 Excel 重新生成。绝对路径还会泄露作者的文件夹结构。                                                                                             |
| `xr:uid` 属性、行的 `spans`、`x14ac:dyDescent`                 | 由 Excel 重新生成的修订标识和布局提示。                                                                                                                                    |
| 行和单元格的 `ph`（显示拼音），以及没有元数据部件的单元格 `cm` | 未建模。拼音指南保留在共享字符串中，只有显示它的标志会丢失。                                                                                                               |
| 共享公式和内联字符串本身                                       | 以等价的普通公式和共享字符串形式写入（值相同）。                                                                                                                           |
| 编辑器不支持的条件格式规则类型                                 | 加载时会报告：`Conditional formatting rule type "..." is not supported and was dropped.`（条件格式规则类型 "..." 不受支持，已被丢弃。）工作表中的其他规则会被保留。        |
| 无法读取的表格或图表部件                                       | 加载时会报告（“A table part could not be read and was dropped”、“Chart ... could not be read; it is kept but not shown”）：图表部件本身会被保留。                          |
| 架构之外的工作表元素                                           | 它无法放置到有效的位置，因此加载时会报告：`the element "..." is not part of the worksheet schema and is dropped on save.`（元素 "..." 不属于工作表架构，保存时将被丢弃。） |

## 被拒绝或报告的内容 {#what-is-refused-or-reported}

编辑器不会静默拒绝任何内容。它通过 `workbook.warnings`（宿主以通知形式显示）报告，并通过抛出错误来报告：

- 加密的包如果没有密码，会要求输入密码（`load/detect.ts`）；密码错误则是一个错误；
- 不受支持或已损坏的部件会按名称报告（“... is kept but not shown”、“... could not be read”）；
- 含有 VBA 宏或外部链接的工作簿会说明它们会被保留，但不会运行或更新；
- 已数字签名的工作簿会说明保存时签名将被移除；
- 若不丢失细节就无法编辑的图表会被标记为 `editBlocked`，并按原样显示和保存；
- `.xlsb` 和 `.ods` 不会被打开；旧版 `.xls` 在保存时会转换为 `.xlsx`，对于二进制读取器无法解码的每个功能都会给出警告；
- 编辑数据表的一部分会被拒绝（“Cannot change part of a data table.”）。

## 保证的已知限制 {#known-limits-of-the-guarantee}

- 逐字节保留的部件，在其所引用的单元格移动时不会被重写。图表、图表工作表、数据透视表缓存以及写入程序已知的其他部件，会因工作表重命名和删除以及其区域的移动而被修补；引用单元格区域的自定义 XML、连接或外部部件会保留旧文本。
- 并发编辑（协作区域）会在共享文档中携带已建模的子集；没有原始包的对等方无法将未建模的部件写回。
- Excel 能否在不修复的情况下打开保存的文件，这项原生检查需要手动完成（`src/core/scripts/xlsx-excel-acceptance.ps1`）；上一次通过运行的日期应记录在项目状态中，而不是本列表中。
