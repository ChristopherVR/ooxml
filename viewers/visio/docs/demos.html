Live demos

The same playground is built once per framework adapter and published next to these docs.

Each demo runs entirely in your browser: drawings are parsed and rendered locally and nothing is uploaded. They open an original sample drawing, or a local .vsdx file you choose. This is a public beta; a demo opening a file is not evidence of Visio fidelity.

Demo Adapter Route
Vanilla JS visio-vanilla-viewer demo/
React visio-react-viewer demo-react/
Vue 3 visio-vue-viewer demo-vue/
Angular visio-angular-viewer demo-angular/
Svelte 5 visio-svelte-viewer demo-svelte/
Solid visio-solid-viewer demo-solid/

Theme

The docs and the demos share one appearance preference. It is stored in localStorage under the VitePress key vitepress-theme-appearance (light or dark; no value follows the system). The home page applies it to the embedded viewer when the viewer reports ready.

Collaboration

To try live sharing, open a demo in two windows of the same browser and use File > Share. See Collaboration for what is and is not supported.

Run them locally

npm ci --ignore-scripts
npm ci --prefix packages/bindings --ignore-scripts
npm run dev
