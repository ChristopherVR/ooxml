visio-viewer / parity

Capability ledger

What exists, how it is evidenced, and what is still missing. A transparent map toward richer Visio support.

Full Microsoft Visio parity is a target, not the current result.

Implementation means code exists for the described subset. It does not mean a Microsoft Visio comparison passed. Generated fixtures exercise selected cases; the original sample is a demonstration, not a reference document.

How to read this ledger

Initial implementation identifies a working code path that still needs broader validation. Partial means known gaps or approximations. Not implemented means no supported end-to-end capability. Not established means there is insufficient evidence to make the claim.

Snapshot: 2 October 2026. The evidence column identifies source locations and test suites to inspect, not a claim that every listed test has passed in your checkout. Final test results belong to the specific commit being evaluated.

What the viewer tells you

Read compatibility notes after opening a document. The core emits structured diagnostic codes with available part, page and shape context. The renderer adds warnings for visual approximations such as unsupported arrow variants, approximate arrow sizing, and browser-based text metrics. Absence of a warning is not a guarantee that every unsupported construct was detected.

Evidence required for a parity claim

  1. Collect genuine Visio-authored fixtures spanning the capability inventory.
  2. Export reference views from a recorded Microsoft Visio version with known fonts and page settings.
  3. Compare geometry, text, styles, connectors and page backgrounds with measured tolerances.
  4. For editing, verify the result in the viewer and after saving and reopening in Visio.
  5. For round-trip, compare untouched XML parts, relationships and unknown content.
  6. Run the same workflow across every advertised framework and browser.

A full-parity percentage is deliberately not shown. No denominator or independent validation corpus has been established.
