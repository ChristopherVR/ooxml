# 局限性

OpenTeams 是一个早期实现。本页列出它不能做的事情，以便你在依赖它之前做出判断。

## 不是 Microsoft Teams

OpenTeams 不是 Microsoft Teams，与 Microsoft 没有任何关联，也不声称在功能上与其对等。它实现了：

- 频道、带回复的帖子、回应、仅作者可用的编辑和删除、搜索和未读计数；
- 在线状态：谁在线、正在输入，以及你自己设置的状态（可用、忙碌、离开）；
- 频道中的会议：音频、视频、屏幕共享和举手，并带有加入前的预览界面；
- 在对话中以链接形式共享的文件，其中 Word、Excel、PowerPoint 和 Visio 文件按名称识别。

它**没有**实现频道之外的一对一或群组聊天、作为独立窗格的主题串、通知、日历、录制、背景模糊或实时字幕。

## 内容工作区

Word 以只读方式预览；Excel 提供本地编辑，并在配置了存储时支持将新的副本保存到频道；Visio 使用其现有的查看器。没有协同编辑、覆盖或带版本的回存。PowerPoint 需要由宿主配置的嵌入式查看器页面。缺失的集成会在窗格中报告。文本读取上限为 2 MiB，原生 Office 读取上限为 32 MiB。

配置了存储时，文件视图支持直接上传、新建空白 Excel 以及元数据搜索。上传会显示忙碌状态并允许重试，但没有字节级进度或取消。失败的批次可能留下未被引用的存储对象；参考服务器对这些对象没有清理约定。文件夹、文档内容索引、文件版本历史和经过验证的文件权限均未实现。

Markdown 支持标题、项目符号、引用、围栏代码、基本强调和网页链接。它尚未实现完整的 CommonMark/GFM、表格、任务列表、嵌套结构或相对链接。原始 HTML 以文本形式显示。

网站和 HTML 附件使用沙盒，不具备同源、弹出窗口或顶层导航权限。有些网站会阻止嵌入，或需要此沙盒不授予的权限。仍可使用外部打开。文件和网站标签页的定义可以在频道中共享；Microsoft Teams 的嵌入式应用平台、身份验证和权限均未实现。标签页创建者检查在客户端运行，需要服务器端授权才能真正生效。

## 安全与隐私

- **无端到端加密。** 聊天以 Yjs 更新的形式经由你的服务器传输，服务器可以读取并存储它们。上传的文件按原样存储。通话媒体在对等端之间使用 DTLS-SRTP（TURN 中继无法解密）。
- **授权是服务器的职责。** 作者和角色检查在客户端运行；恶意客户端可以写入服务器接受的任何内容。
- **参考服务器没有用户账户。** 它的令牌是保存在浏览器中的一个共享密钥，而不是按用户的身份验证。参见[参考服务器不做的事情](/zh/server#what-the-reference-server-does-not-do)。
- **在线状态是参考性的，且未经身份验证**，与任何 Yjs awareness 一样：客户端可以声称任何名称。
- 对等端发送的一切内容在读回时都会重新校验，并以文本而非标记的形式渲染。

## 规模

- **网状通话**将每位参与者与其他所有人相连。这不需要媒体服务器，适合少数几个人（默认上限为 12），而不适合网络研讨会。
- **历史会不断增长。** 参考服务器为每个房间保留一个快照，且从不压缩。
- **单个服务器进程。** 参考服务器将房间保存在内存中，不支持水平扩展。

## 本地模式和在线演示

`mode: 'local'` 使用 `BroadcastChannel`，因此只有同一浏览器中同一站点的标签页能相互看到。不会向任何服务器发送任何内容，文件仅按名称共享（没有地方可以上传），共享文档保存在该浏览器的 `localStorage` 中。[在线演示](/demos)以这种方式运行，因为 GitHub Pages 无法托管服务器。

## 跨网络通话

公共 STUN 在开放网络上可用。在对称 NAT 或严格防火墙之后，你需要自己的 TURN 服务器；没有它，部分通话将无法连接。摄像头和麦克风需要 `localhost` 或 HTTPS。
