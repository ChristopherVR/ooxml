How the samples are made

Generated by scripts in the repository

Every file here is written by a script in the repository, mostly through the same library the editors run on, so each one can be rebuilt byte for byte and reviewed like any other source. The companies, places and people in them are invented. The text is set in open fonts (Rubik, Noto Sans and Noto Serif), and every picture is drawn by the script that needs it.

Opening a sample downloads that one file from this site and adds a copy to the library in your browser. Nothing is fetched until you ask for it, and nothing you change is sent anywhere.
