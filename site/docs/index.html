Everything built in this repository, in one place: the five apps and their framework packages, the headless library underneath them, the shared UI elements, the MCP server for agents, and the suite that puts them together.

Apps

Each app has its own site with a developer guide, a user guide and live demos

Build with it

The packages the apps are made of, usable on their own
ooxml-core Parse, edit, validate and write every Office format with no UI: WordprocessingML, SpreadsheetML, PresentationML, DrawingML, charts, SmartArt, maths, encryption and collaboration. npm i ooxml-core ooxml-ui The shared custom elements every app is built from: ribbons, menus, dialogs, title bars, status bars, presence and SmartArt, plus each product editor. npm i ooxml-ui ooxml-mcp One Model Context Protocol server for every format, so an agent can read, create and change documents, workbooks and decks. npm i ooxml-mcp Agents and automation How the MCP tools map onto the headless document operations, and how to run them against files on disk. Guide Legacy formats The sibling ole2 package reads .doc, .xls and .ppt and the compound-file container, and is inlined into the editors. npm i @christophervr/ole2 Releases Every package is versioned from conventional commits and published with provenance. The changelogs are on each package page. npm
