All apps

    One core under every app

    Every app reads and writes its files through the same open-source library, so a chart, a picture or a table behaves the same way in a slide as it does on a page.

    ooxml-core
    The shared engine: file packaging, drawings, charts, SmartArt, editing and live collaboration.
    pptx-viewer
    PowerPoint components for React, Vue, Angular, Svelte and plain JavaScript.
    docx-viewer
    Word components for the same frameworks, plus Solid. Still in beta, so expect gaps.
