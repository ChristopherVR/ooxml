# Native accessibility metadata

`native-alt-text.vsdx` was generated by Microsoft Visio 16 through an owned,
invisible COM instance on 2026-10-12. It contains one rectangle with a native
title and description on the rectangle and page, no imported document content.

The Title property uses `User.visAltText`; AlternativeText uses
`User.visAltDescription`. This build rejects the second direct metadata property
setter with an unexpected EOF error, so the generator adds the second User row
through ShapeSheet and verifies the public AlternativeText getter.

Run `scripts/visio-alt-text-acceptance.ps1 -OutputDirectory <temporary-folder>`
to generate the source, apply core edits, reopen both edited and cleared versions
in Visio and inspect both public properties. `native-alt-text-editing.json`
records the observed shape and page results. Unit tests additionally cover inherited values,
local overrides, preservation and refusal of formula-driven metadata.

References: [Shape.Title](https://learn.microsoft.com/en-us/office/vba/api/visio.shape.title)
and [Shape.AlternativeText](https://learn.microsoft.com/en-us/office/vba/api/visio.shape.alternativetext).
