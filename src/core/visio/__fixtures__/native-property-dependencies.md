# Native Shape Data dependencies

Generated by an owned Microsoft Visio 16 COM instance on 2026-10-12 using
`scripts/visio-property-dependencies.ps1`. Two synthetic rectangles exercise
`Prop.Offset = Width/1IN*0.25` and a second shape's PinX dependent on that property.
The XML section name is `Property`, while formula references use `Prop`.

After the core resizes the first rectangle from four to eight inches, Visio
reopens the output with Width 8, Offset 2 and the dependent PinX 2.
`native-property-dependencies.json` records these native values. This fixture
contains no imported template content. Native data-graphic masters, dynamic
formula dependencies and automatic graphic regeneration remain separate gaps.
