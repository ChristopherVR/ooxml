# Ordinary table border geometry

Generated by `scripts/record-word-table-borders.ps1` using an owned Microsoft Word 16.0.20430 application. The generator copies the previously recorded table-footnote and nested-frame synthetic documents, adds colored outer borders and cell fills, then saves DOCX and exports PDF. `scripts/measure-word-table-borders.py` records native border rectangles and ink positions in PDF points. No user documents are opened.

The thirteen supported samples cover half-point, three-point and asymmetric borders, cell margins, exact and automatic enclosing rows, early and late footnote references, and repeated outer headers. Shared grid rows include their top stroke; the final physical fragment reserves its bottom stroke. Exact rows retain clipping, including partially visible glyphs. For the 22-point enclosing row, PDF text extraction omits the trailing paragraph although rasterized native output contains its upper glyph pixels. This is a clipping case, not a reason to delete source text.

`enclosing-border-split` records independent inner-cell continuation (15 and 17 lines on the first page). The bounded one-row, automatic, top-aligned profile with one footnote reference is also checked by the `independent-inner-notes` corpus. Multiple inner rows, deeper tables and fixed-height or centered inner stories remain outside that admission. This corpus does not claim inner repeated headers, vertical-merge geometry, conflicting border profiles, or font raster parity.

All saved document XML and source models are checked without edits. Binary fixture hashes in the handoff manifest refer to committed Git blobs.
