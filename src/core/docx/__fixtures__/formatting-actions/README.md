# Native Word formatting actions

These synthetic documents were generated by
`scripts/record-word-formatting-actions.ps1` in a separate hidden Word instance.
The recorded desktop build is 16.0.20430. It supplies desktop interoperability
evidence, not certification against every current Microsoft 365 client.

`baseline.docx` contains Arial 12 pt "Format me". With revision and formatting
tracking enabled, the other documents apply bold to "Format", apply bold then
italic, apply bold then remove it, or insert "!" and apply bold to that insertion.
The reference records native revision types and Reject All results. Successive
format changes share a revision; returning to the baseline removes it. Formatting
on a pending insertion has independent history. No user documents are used.

The shared editor tests reproduce these actions, compare revision kinds, and
verify rejection after package and standalone export. Unsupported structural,
paragraph and opaque-property editing transactions remain outside this slice.
