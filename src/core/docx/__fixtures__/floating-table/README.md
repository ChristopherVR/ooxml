# Floating tables

Generated by `src/core/scripts/docx-word-floating-table-probe.ps1` with an owned Microsoft Word 16.0.20527 application through its documented COM object model. Each `<case>.docx` is a hand-written source document (Courier New 11 pt, Letter page with 1 in margins, compatibility mode 15) holding a two-row, 3000-twip fixed table with a `w:tblpPr` frame and outer borders, between a short paragraph and a long one. `word-positions.json` records, in points from the page's top-left (`Range.Information`), the first cell's text position and the start of every line of the paragraph after the table. No user documents are opened.

The cases cover `margin`, `page` and `text` anchors, `tblpX`/`tblpY` offsets, `tblpXSpec` right and center, `tblpYSpec` top, absent anchors and asymmetric `*FromText` distances. Observed: the table takes no room from the flow; `vertAnchor="text"` measures from the top of the paragraph that follows the table; an absent `vertAnchor` measures from the top margin (an absent `horzAnchor` gives the same position as the margin and the column on this single-column page); text on both sides of a table in the middle of the column continues past it; the distances widen the area text keeps clear. Word also fills a 27 pt gap beside a table with short words (`text-offset`); the layout leaves gaps narrower than 36 pt empty, so that case is checked for position only.
