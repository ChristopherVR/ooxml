# AutoFit table columns

Generated by `src/core/scripts/docx-word-autofit-probe.ps1` with an owned Microsoft Word 16.0.20527 application through its documented COM object model. Each `<case>.docx` is a hand-written source document (Courier New 11 pt, cell margins 108 twips, Letter page with 1 in margins, compatibility mode 15 unless the name ends in `-mode14`, `-mode12` or `-mode0` for no mode). Every table carries a deliberately wrong grid of 1000 twips per column: Word recomputes an AutoFit table's columns when it opens a document, so the grid it saves back (`w:tblGrid/w:gridCol`, twips) is its own layout. `word-grids.json` records that grid per case. The two `consistent-*` cases instead carry the grid Word itself would write (equal to the cells' preferred widths): Word recomputes those too, shrinking three 5000-twip columns to the text column and widening a column for a long word, so the saved grid of an AutoFit table is never authoritative. No user documents are opened.

The cases cover automatic, percentage and twips table widths (wider and narrower than the content, and narrower than its minimum), twips and percentage cell preferred widths (one cell, a column with two widths, preferred widths over the available width, a preferred width under the content minimum), horizontally merged cells over equal and unequal columns with unbreakable and wrapping text, an empty cell, paragraph indents, several paragraphs, words split across runs, a table indent and a fixed-layout control. `table-autofit.test.ts` lays out every source document and checks each cell edge against Word's grid to one twip.

Observed in the recordings: column widths are whole twips; a content width is rounded up to the next twip; an empty cell needs 6 twips besides its margins; in compatibility modes 12 and 14 and with no mode, an automatic table may be as wide as the text column plus the first cell's left margin, and a percentage width is taken of the text column plus both outer cell margins. Positioning of those legacy tables (the outdent by the cell margin) is not covered here.
