# Native move export reference

Recorded 2026-10-07 with desktop Word build 16.0.20430 (Click-to-Run
16.0.20430.20140). The installed licenses are perpetual editions; this is
bounded desktop interoperation evidence, not M365 subscription certification.

`core-created.docx` contains two independently named moves by Ada, generated by
the standalone core writer. `word-saved.docx` is Word's saved version, and
`word-accepted-first.docx` accepts only FirstMove's moved-from revision in Word.
`word-rejected-first.docx` independently rejects that move in Word.
`reference.json` records native revision types, names and text. Reproduce with
`scripts/record-word-review-moves.ps1 -InputPath <core-created.docx>`.

Native observations: moved-from runs need `w:t`, rather than `w:delText`.
The numeric names move1/move2 remain linked and resolve together. UUID-shaped
names retained as range names, but Word converted their contents into separate
insertion/deletion revisions. The writer therefore maps editing identities to
numeric names when exporting. Tests verify the generated XML, Word-normalized
model, independent resolution and save/reopen.
