# Independently continued inner footnote cells

Recorded with an owned Word 16 application by `scripts/record-word-inner-note-stories.ps1`, starting from the previously recorded `ordinary-table-borders/enclosing-border-split.docx`. It moves the reference to the first line or the second cell, and extends either story to thirty explicit lines. PDF point measurements use `scripts/measure-word-table-borders.py`. No user documents are opened.

Together with the source fixture, these probes establish independent continuation of a single automatic, top-aligned nested row with one actual footnote reference: the referenced story can defer its marker while its neighbor fills the physical row. The continuation is reflowed through the existing source row layout from each paragraph's remaining token. Following direct outer text starts after the longest remaining inner story. A final page containing only outer text does not reserve a phantom completed inner border.

This admission excludes multiple interacting footnote references (including repeated markers for one note), multiple inner rows, deeper tables, fixed-height or centered/bottom-aligned inner rows, inner repeated headers, leading outer paragraphs, noted trailing paragraphs and explicit paragraph keeping/page-break rules. It does not establish vertical-merge layout, arbitrary paragraph keeping rules, or font raster parity. Existing exact-row partial glyph clipping remains covered by the separate ordinary border corpus.
