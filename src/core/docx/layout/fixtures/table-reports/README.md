## What Word does with them

Opened read-only in Microsoft Word 16 through its documented COM object model (`Documents.Open`, `ComputeStatistics`, `Range.Information`, `ExportAsFixedFormat`), with no repair prompt:

- **t02**: one page. The table stays inside the text column with equal columns; the words break inside their cells ("Colo|nne1").
- **t03**: one page. The table stays inside the text column. The tokens break inside their cells, at hyphens and slashes where they have them and anywhere for the IBANs. Word also narrows the label column ("Référen|ce"); the layout engine keeps narrow columns at their minimum and only caps the widest, so its column split differs while the table width matches.
- **t10**: one page. Both the header and the footer tables are drawn with their single borders.
- **t14**: three pages. The row moves whole to page 2 and is cut at the bottom of that page: paragraphs 1 to 54 are visible, the rest are clipped and do not appear on any page. Page 3 holds only the paragraph after the table. Word does **not** split a "keep row together" row that is taller than a page, so #323 is Word's behaviour and the layout engine keeps it.
- **t15**: one page. The centred table fits the text column.
