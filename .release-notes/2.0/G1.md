## Security

- `ooxml-core`: every security fix in this release is now guarded by a regression corpus that runs with the unit tests on each change. Each case is a small generated input fed to a public entry point (loading a PowerPoint deck, Word document or Excel workbook, checking a digital signature, applying a collaboration update, validating a Teams update, or an automation write) in a process with its own time and memory limits and no network access. A change that lets a hostile input hang, exhaust memory, reach the network, run script or pass a check it should fail now fails the build. There is no API change.
