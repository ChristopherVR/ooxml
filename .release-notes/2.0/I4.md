## Fixed

- `ooxml-ui` and PowerPoint viewers: a dialog opened from the File page, such as the PDF options of File > Export or File > Options, keeps keyboard focus when the File page closes, so Escape closes it in every binding. Before, focus went back to the File tab and Escape did not reach the dialog in the Vue, vanilla and Svelte viewers, and only sometimes in the Angular viewer.
- `ooxml-ui` and `pptx-vue-viewer`: the slide thumbnails in the Vue viewer are spaced 4 px apart, as in the other bindings, instead of 8 px.
- `pptx-angular-viewer`: the custom shows button in the ribbon shows "+ Show" with the tooltip "Create custom show", as in the other bindings, in every display language. It showed the word "Show" alone, translated as the verb in some languages.
