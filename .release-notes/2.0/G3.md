## Fixed

- `ooxml-ui/pptx`: `<pptx-ui-title-bar>` now finishes its update lifecycle, so a host that awaits its `updateComplete` continues instead of waiting forever. Changing its `placement` attribute still redraws it at once.
- `ooxml-ui/teams`: the shared Teams reset stylesheet now carries the default value of every `--office-*` token it uses, so team workspace elements render correctly before the theme is installed, like the other elements.
- `ooxml-ui/teams`, `ooxml-core/teams`: the channel a new workspace starts with is shown in the display language ("Allgemein" and its topic in German, and so on in every supported locale) while it keeps its original name and topic. A renamed channel shows its name as typed. `ooxml-core/teams` exports the starting channel as `DEFAULT_CHANNEL`.
