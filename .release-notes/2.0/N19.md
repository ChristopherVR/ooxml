## Accessibility

- Every control's accessible name now contains the text it shows (WCAG 2.5.3, Label in Name), so speech input users can say what they see. This covers the OOXML Office suite, `ooxml-ui` and every PowerPoint binding. Captions, tooltips and icons stay as Microsoft Office shows them; only names changed.
- `ooxml-ui` status bar: the zoom percentage button is named by the percentage it shows, then what it does, for example "100%, Zoom to fit", in `office-ui-status-bar`, `pptx-ui-status-bar` and the Svelte viewer toolbar. The new `zoomFitName` helper (exported from `ooxml-ui` and `ooxml-ui/pptx`) builds that name.
- `ooxml-ui/pptx`: the Text Shadow and Character Spacing icons draw their bold letters as outlines instead of text, so they look as before and the buttons are named only by their commands.
- `ooxml-ui/pptx`: Design > Fonts tiles are named by what they show, then the scheme, for example "Aa Aptos Display / Aptos: Office", in every binding, the suite and Visio.
- `ooxml-ui/xlsx`: the formula bar's Insert Function button keeps its name, and its fx glyph is now an icon rather than text.
- `ooxml-ui/docx`: Word ribbon commands whose caption is shorter than their command name have their own accessible names in every locale, for example Insert > Pictures is named "Insert pictures" ("Bilder einfügen", "Insérer des images", "Insertar imágenes", "插入图片"). Dialogs, menus and tooltips keep their wording.
- `ooxml-ui/visio`: gallery buttons such as Design > Backgrounds, Borders & Titles, Re-Layout Page and Insert > Callout show their caption in the display language, matching their names.
- OOXML Office: the account button is named by the profile, with the initials drawn as a picture, and the workspace switcher is named by the workspace it shows, with "Switch workspace" as its tooltip.

## Changed

- `pptx-viewer-locales`: the French Notes title is "Notes", as PowerPoint shows it, matching the Notes button.
- `ooxml-ui`: hosts or tests that find the zoom percentage button by the name "Zoom to fit" should match the new name, which starts with the percentage, or select `[data-id="zoomFit"]`.
- `ooxml-ui/pptx`: hosts that translate `pptx.gallery.themeFonts.scheme` or `pptx.gallery.themeFonts.current` should start the text with `Aa {{major}} / {{minor}}`, the text the tile shows.
