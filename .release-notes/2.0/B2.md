## Breaking

- `ooxml-core/pptx`: `inspectSignaturesFromBuffer` now verifies the signatures and returns a `SignatureSummary` (`{ state, signatures }`). `parseSignaturesFromBuffer` and `PackageSignatureInfo` are removed: they only parsed the signature parts and could not tell a valid signature from a forged one. See the migration guide.
- `ooxml-core/xlsx`: `Workbook.signatures` is now a `SignatureSummary` instead of `{ count, parts }`.
- `ooxml-core/docx`, `ooxml-core/xlsx`: loading a signed document no longer adds an English "signature not verified" message to `warnings`. Read `signatures.state` and word it with `signatureStateText` from `ooxml-core/i18n`.
- `ooxml-core/pptx/signature-node`: `canonicalizeNode`, `canonicalizeSignedInfoXml`, `getNodeLocalName` and `getFirstDescendantElementByLocalName` are no longer exported. Use `signature.canonicalize` from `ooxml-core/opc`.

## Migration

- `ooxml-core`: show a document as signed only when `signature.isVerifiedSignatureState(summary.state)` (from `ooxml-core/opc`) is true. `hasDigitalSignatures` still says only that signature parts exist. The migration guide has before and after code.
- `ooxml-core`: `xml-crypto` is no longer needed as a peer dependency for signature verification.

## Added

- `ooxml-core/opc`: the `signature` namespace adds `verifyPackageSignatures`, `verifyPackageSignatureSummary`, `signatureStateOf`, `summarizeSignatures` and the `SignatureState` type (`unsigned`, `verified`, `verified-untrusted`, `invalid`, `unsupported`) verify the digital signatures of Word, Excel, PowerPoint and Visio packages in browsers as well as Node. They check the signature value, every signed part and that the signature covers the content. A browser has no trust store, so an intact signature from any signer is `verified-untrusted` there; the Node verifier still checks your configured trust roots and revocation.
- `ooxml-core/docx`, `ooxml-core/xlsx`, `ooxml-core/pptx`, `ooxml-core/visio`: a signed document carries its verified state as `signatures` (`model.signatures`, `Workbook.signatures`, `PptxData.signatures`, `VisioDocument.signatures`).
- `ooxml-core/i18n`: `signatureStateText` and `signatureStringsFor` word each signature state in English, French, German, Spanish, Simplified Chinese, Japanese and Korean.
- `ooxml-ui`: `<office-ui-signature-status>` shows a document's signature state from a `SignatureSummary` as a status bar badge (`variant="badge"`), a load notice (`variant="notice"`) or an info panel listing each signer (`variant="panel"`), worded in its `locale`. It emits `office-signature-activate` and `office-signature-dismiss`.

## Changed

- Word viewers, Excel viewers, Visio viewers: a signed document shows its verified state in the status bar, in a notice under the ribbon and on File > Info: Signed, Signed (signer not verified), Invalid signature or Signature not verified, in every editor language. The notice says that saving changes removes the signatures. Nothing is shown for an unsigned document.

## Fixed

- `ooxml-core/opc`, `ooxml-core/pptx`: signatures that Word, Excel and PowerPoint write are no longer reported as invalid in the browser. The previous check compared digests of the raw parts, which never match Office's signed references.
- `ooxml-core/pptx/signature-node`: a Word 2007 signature over pretty-printed relationships parts now verifies; the canonicalization used before rendered it differently from the signer.
- `ooxml-core/opc`, `ooxml-core/pptx`: a signature with a relationships part stored as UTF-16 now verifies, and PowerPoint reads UTF-16 parts instead of loading an empty deck.
- `ooxml-core/opc`: a signature that uses a method or key type the verifier does not implement is reported as `unsupported` rather than invalid.
- `ooxml-core/pptx`: a signed deck whose relationships parts the strict reader rejects (markup-compatibility attributes, for example) now opens instead of failing to load, and is shown as not verified.

## Security

- All packages: no product shows a document as signed because it merely contains a signature part. Badges, status bar entries, info panels and load notices in Word, Excel, PowerPoint and Visio show the verified state.
