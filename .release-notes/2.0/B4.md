## Fixed

- `pptx-vue-viewer`: `pptx-vue-viewer.css` is valid CSS again, so bundlers minify it without warnings. A comment in one component's styles lost its opening `/*` during the build and shipped as raw text, which esbuild reported as an unexpected character and an unterminated string, and which Lightning CSS reported as an empty selector. Every component style now reaches the stylesheet unchanged.
- `pptx-vue-viewer`: the building-block canvas and toolbar (`.pptx-vue-bb-canvas`, `.pptx-vue-bb-toolbar`) now get their layout styles. The build kept only scoped component styles, so these unscoped ones never shipped.
- PowerPoint viewers, Word viewers, Excel viewers, Visio viewers and OpenTeams viewers: every stylesheet a package publishes is now minified with esbuild and Lightning CSS before release, and any warning from either fails the build.
