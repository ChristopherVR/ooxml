## Breaking

- `ooxml-core`: each formula now has a work budget and a text budget, next to an array budget that used to cover a whole recalculation and now covers one formula. The work a formula may spend is priced from what the engine measurably takes, about three seconds of matrix products, `LAMBDA` calls, criteria and lookup scans repeated over arrays, sorting and pattern matching. A formula past it returns `#NUM!`, usually before any of the work runs; every other formula still computes. Workbooks Excel calculates in ordinary time stay well inside it; formulas such as `MMULT` of two 1,500 by 1,500 arrays, `MDETERM` or `MINVERSE` of a 1,000 by 1,000 array, more than about six million `LAMBDA` calls, or `COUNTIF` over 20,000 cells repeated for 20,000 criteria return `#NUM!` instead of a result.
- `ooxml-core`: `CalcEngine` has a new `stopped` member, so code that implements the interface itself must add it.

## Added

- `ooxml-core`: `CalcEngineOptions.timeLimitMs` bounds how long one recalculation may run, and `CalcEngineOptions.workCap` how much work one formula may need before the recalculation gives up (for a quick first attempt). Past either the recalculation stops between formulas, `CalcEngine.stopped` says why, the formulas it did not reach keep their previous values, and the next recalculation computes everything. A recalculation also stops this way, rather than returning errors, when its results would hold more than 50 million array cells or 512 million characters of text.
- `ooxml-core`: `calculateOnOpen(workbook, { timeLimitMs })` runs the calculation a workbook asks for on open (`calcPr fullCalcOnLoad`) and returns whether it ran and why it stopped, if it did. `needsCalculationOnOpen` tells whether a workbook asks for it, `calculateOnOpenCells` returns what the calculation wrote and `applyCalculatedCells` writes that into another copy of the same file.
- `ooxml-ui`: the Excel editor's `setWorkbook` accepts `{ calculate: false }` for a workbook already calculated.

## Changed

- `ooxml-ui`: the Excel editor reads every file on the page, as before, so a file that needs no calculation opens as fast as before. A file that asks for a full calculation on open is calculated on the page for at most as long as reading it took (at least a quarter of a second), with no formula allowed more than about a quarter of a second of work; most workbooks finish there. Otherwise a worker reads the file again, runs the whole calculation off the page and sends back only the cells it wrote, so slow formulas no longer freeze the page. The calculation stops after ten seconds; the formulas it did not finish then show the values the file was saved with, and a notice says that F9 recalculates. Without a worker the calculation runs on the page under the same limit. Bundlers that handle `new Worker(new URL(..., import.meta.url))` pick up the new `xlsx-open-worker.js` file automatically. A page's Content Security Policy must allow workers from its own origin (`worker-src 'self'`) for the calculation to leave the page.

## Fixed

- `ooxml-core`: workbooks with `LET`, `LAMBDA` or the functions that take a `LAMBDA` (`REDUCE`, `MAP`, `SCAN`, `BYROW` and the others) are saved so that Excel opens them: their names are stored with the `_xlpm.` prefix Excel requires. Reading a file removes the prefix, so the formula shows the names as Excel does.
- `ooxml-core`: formulas compare text as Excel does. Comparisons, `COUNTIF` and the other criteria functions, `XMATCH`, `XLOOKUP`, `UNIQUE`, `SORT` and `SWITCH` treat "ß" as "ss", "æ" and "œ" as their letters, ligatures as their letters and final sigma as sigma, stay accent-, width- and kana-sensitive, and let hyphens and apostrophes only break ties. `MATCH`, `VLOOKUP`, `HLOOKUP`, wildcards and `SEARCH` compare character by character, so `SEARCH("ς","ΣΑΣ")` is 1.
- `ooxml-core`: exact lookups compare numbers exactly, so `MATCH(0.3,...)` no longer finds `0.1+0.2`, while `=` and `COUNTIF` still treat the two as equal.
- `ooxml-core`: in criteria, `~` is plain text unless the criterion holds `*` or `?`, and a trailing `~` in a pattern is ignored. A blank criterion cell matches zeros rather than blanks, and `DCOUNTA` counts empty text.
- `ooxml-core`: `&` and `CONCATENATE` cut text at 32,767 characters, `CONCAT`, `TEXTJOIN` and `ARRAYTOTEXT` return `#CALC!` past it, `TEXT` returns `#VALUE!` for formats or results over 255 characters, `BASE` pads to at most 255 digits, and `LOWER` keeps a capital sharp s, all as in Excel.
- `ooxml-core`: `REGEXTEST`, `REGEXEXTRACT` and `REGEXREPLACE` run on the formula engine's own matcher, so no pattern can freeze a recalculation: one that would take too long returns `#NUM!`. Patterns with nested repeats, such as `(a+)+`, which used to return `#VALUE!`, now work, and long texts are no longer refused. `REGEXREPLACE` with an occurrence now uses that match's own groups and surrounding text.

## Security

- `ooxml-core`, `ooxml-ui`: a small crafted workbook can no longer hang or crash the Excel editor when it opens, through slow matrix, `LAMBDA`, text, pattern or repeated-scan formulas: each formula is bounded, the calculation on open runs off the page under a time limit, and what a recalculation stores is bounded.

## Performance

- `ooxml-core`: `MMULT` runs about three and a half times faster (two 1,000 by 1,000 arrays in about one and a half seconds instead of five), and a nearest-match `XLOOKUP` or `XMATCH` repeated over many lookup values reads the searched cells once per recalculation, so 1,000 such lookups in 100,000 rows take about a second instead of six.

## Accessibility

- `ooxml-ui`, `ooxml-core`, Excel viewers: screen readers can explore the Excel grid as a table. The visible cells are grid cells in rows, with column and row headers, and the active cell is announced with its table column, formula and comment. A cell's row and column indices are the sheet's own, as Excel reports them: B2 is row 2, column 2, and the header row and row headers take no index.
- `ooxml-ui`, Excel viewers: the active cell's announcement stays correct after an undo, a reload or a recalculation that leaves the selection where it is, and pictures on a sheet are announced once, by their alt text.
- `ooxml-core/xlsx`: adds `describeCell` and `accessibleWindow`.
