## Breaking

- `ooxml-core`: each recalculation now has a work budget and a text budget next to the existing array budget. A formula that exhausts one returns `#NUM!`, and so does every formula after it in the same recalculation. Ordinary workbooks stay well inside them; formulas such as `MMULT` of two 1,000 by 1,000 arrays, millions of `LAMBDA` calls in one formula, or `COUNTIF` repeated over an array of 20,000 criteria now return `#NUM!` instead of a result.

## Changed

- `ooxml-ui`: the Excel editor opens files in a worker and runs the calculation a workbook asks for on open (`calcPr fullCalcOnLoad`) there, so neither a large file nor slow formulas freeze the page. The calculation on open stops after ten seconds; the workbook then shows the values it was saved with, and a notice says that F9 recalculates. Bundlers that handle `new Worker(new URL(..., import.meta.url))` pick up the new `xlsx-open-worker.js` file automatically; without a worker the editor opens files on the page as before. A page's Content Security Policy must allow workers from its own origin (`worker-src 'self'`).
- `ooxml-core`: `calculateOnOpen(workbook)` runs the calculation a workbook asks for on open, and the Excel editor's `setWorkbook` accepts `{ calculate: false }` for a workbook already calculated.

## Fixed

- `ooxml-core`: formulas compare text as Excel does. Comparisons, `COUNTIF` and the other criteria functions, `XMATCH`, `XLOOKUP`, `UNIQUE`, `SORT` and `SWITCH` treat "ß" as "ss", "æ" and "œ" as their letters, ligatures as their letters and final sigma as sigma, stay accent-, width- and kana-sensitive, and let hyphens and apostrophes only break ties. `MATCH`, `VLOOKUP`, `HLOOKUP`, wildcards and `SEARCH` compare character by character, so `SEARCH("ς","ΣΑΣ")` is 1.
- `ooxml-core`: exact lookups compare numbers exactly, so `MATCH(0.3,...)` no longer finds `0.1+0.2`, while `=` and `COUNTIF` still treat the two as equal.
- `ooxml-core`: in criteria, `~` is plain text unless the criterion holds `*` or `?`, and a trailing `~` in a pattern is ignored. A blank criterion cell matches zeros rather than blanks, and `DCOUNTA` counts empty text.
- `ooxml-core`: `&` and `CONCATENATE` cut text at 32,767 characters, `CONCAT`, `TEXTJOIN` and `ARRAYTOTEXT` return `#CALC!` past it, `TEXT` returns `#VALUE!` for formats or results over 255 characters, `BASE` pads to at most 255 digits, and `LOWER` keeps a capital sharp s, all as in Excel.

## Security

- `ooxml-core`, `ooxml-ui`: a small crafted workbook can no longer hang or crash the Excel editor when it opens, through slow matrix, `LAMBDA`, text or repeated-scan formulas.

## Performance

- `ooxml-ui`: opening an Excel workbook reads the file off the page.
