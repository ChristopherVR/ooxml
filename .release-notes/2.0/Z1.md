## Breaking

- All packages: every package requires Node.js 22.3 or newer and declares `"engines": { "node": ">=22.3" }`. `ooxml-core` reads the heap limit Node reports through `process.getBuiltinModule`, which Node added in 22.3, to size the memory budget of a Visio read or edit. On an older Node that budget assumes a 1 GiB heap. Before, `ooxml-core`, `ooxml-ui`, the MCP packages and `openteams-server` declared Node 22, the OpenTeams viewers Node 20, `@christophervr/pptx-viewer` Node 18, and the other packages nothing.
