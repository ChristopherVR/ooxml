## Migration

- `ooxml-core`, `ooxml-ui`, `pptx-viewer-core`, PowerPoint viewers, Word viewers, Excel viewers and Visio viewers: these packages now use `emf-converter` 5, which loads image decoders and colour data on demand from `dist/browser-chunks/` and `dist/node-chunks/`. Package managers and bundlers need no change. If you copy compiled files by hand, deploy those folders next to the entry files and keep their relative paths.

## Changed

- All packages: every package is built and tested against current releases of its dependencies, including `emf-converter` 5, `mtx-decompressor` 1.9 and Angular 22.2.
- `pptx-vue-viewer`: icons now come from `@lucide/vue`, because `lucide-vue-next` is deprecated. The icons look the same.
- `@christophervr/pptx-viewer` and `pptx-viewer-core`: `@christophervr/pptx-viewer` accepts `framer-motion` 14, and `pptx-viewer-core` accepts `@xmldom/xmldom` 0.9, as peers. The earlier supported versions still work.
- Office suite: the desktop app moves to Tauri 2.12.7 and `rfd` 0.18. Building it from source needs Rust 1.92 or later.
- Word viewers, Excel viewers, Visio viewers and OpenTeams viewers: the Solid bindings still require `solid-js` 1.9. Solid 2 is not supported yet, because the stable Solid compiler plugin for Vite does not support it.
