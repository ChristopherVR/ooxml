## Migration

- `ooxml-core`, `ooxml-ui`, `pptx-viewer-core` and the viewer packages now use `emf-converter` 5. It loads image decoders and colour data on demand from `dist/browser-chunks/` and `dist/node-chunks/`. Package managers and bundlers need no change. If you copy compiled files by hand, deploy those folders next to the entry files and keep their relative paths.

## Changed

- All packages are built and tested against the latest releases of their dependencies, including `emf-converter` 5, `mtx-decompressor` 1.9, Angular 22.3, Vitest 5.1, Playwright 1.65 and Bun 1.4.4.
- `pptx-vue-viewer` now depends on `@lucide/vue`, because `lucide-vue-next` is deprecated. Icons are unchanged.
- `@christophervr/pptx-viewer` accepts `framer-motion` 14, and `pptx-viewer-core` accepts `@xmldom/xmldom` 0.9, as peers. Earlier supported versions still work.
- The OOXML Office desktop app moves to Tauri 2.12.7 and `rfd` 0.18. Building it from source needs Rust 1.92 or later.
- The Solid bindings still require `solid-js` 1.9. Solid 2 is not supported yet, because the stable Solid compiler plugin for Vite does not support it.
