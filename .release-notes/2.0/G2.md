## Fixed

- Office suite: Ctrl+S pressed straight after an edit Visio is still applying, such as an arrow-key nudge, now saves the drawing once the edit is done. Before, the save failed with "Wait for the current document operation" and the tab stayed unsaved.
- Office suite: Ctrl+S pressed while a document is being saved, exported or changed by the assistant is no longer dropped. The document is saved once that work is done.

## Accessibility

- `ooxml-ui`, the Word, Excel, PowerPoint, Visio and Teams viewers, and the Office suite: every change to them is now checked in a real browser before it can be released. Tab goes round the page without getting stuck and passes through every part of the window, F6 moves between the regions, dialogs keep focus inside, close on Escape and give focus back, and saving or applying an assistant edit leaves focus where it was. PowerPoint is checked in all five bindings.
- The same checks run axe-core on the main screens in light mode, dark mode and on a phone, and fail on any new critical or serious problem. Known problems are listed with the work that fixes them, and that list can only get shorter.
- They also check what a screen reader is told about Word, Excel and PowerPoint documents, the contrast of every accent colour in light and dark mode, that the window still works at 320 by 256 pixels (400% zoom), and that a saved file keeps its alt text, headings, table header rows and language. That last check also runs when the code that writes Word, Excel or PowerPoint files changes.
