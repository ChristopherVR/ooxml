## Performance

- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: exact `VLOOKUP`, `HLOOKUP`, `XLOOKUP`, `XMATCH`, `MATCH` and `INDEX`/`MATCH` searches over the same range now share an index within a recalculation, in both search directions. Thousands of lookups over one table no longer cost a scan each, and every result, including mixed types, wildcards and reverse searches, stays what a scan returns.
- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: identical `SUM`, `PRODUCT`, `COUNT`, `COUNTA`, `AVERAGE`, `MIN`, `MAX` and `MEDIAN` calls over the same large ranges are computed once per recalculation.
- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: an edit that changes a row's automatic height now recalculates only what depends on the edited cells. It used to rebuild the dependency graph and recalculate the whole workbook. Hiding rows, setting a height by hand and other structural edits still recalculate fully, so `SUBTOTAL` and `AGGREGATE` keep following hidden rows.
- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: `forEachCellInRange` now costs what the range covers when that is smaller than the sheet, which makes undo and redo of Replace All on large sheets far faster.
- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: volatile formulas are tracked as a list, so an edit no longer visits every formula in the workbook to find them.
- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: selecting a whole column no longer builds a list of every row to decide whether Ungroup is available.
- `ooxml-ui/xlsx` and Excel viewers: on sheets with more than 20,000 stored rows, the Excel status bar fills in the selection's sum, average and count just after the new selection is drawn, so selecting a whole column no longer waits for them.

## Fixed

- `ooxml-core/xlsx`, `@christophervr/xlsx-core` and Excel viewers: in iterative calculation, `SUMIF`, `COUNTIF` and the other criteria functions now read current values on every pass. They used to keep the values from their first read.
