## Breaking

- PowerPoint viewers (`pptx-react-viewer`, `pptx-vue-viewer`, `pptx-angular-viewer`, `pptx-svelte-viewer`, `pptx-vanilla-viewer`, and `ooxml-ui/pptx`) no longer download a presentation's linked pictures, audio, video or online videos when it opens. As in Microsoft PowerPoint, a security bar under the ribbon says "References to external pictures and other media have been blocked" and offers **Enable Content**, which reopens that presentation as it stands with its linked content: saved and unsaved edits and the slide on screen are kept, unsaved edits stay unsaved, and undo history starts over. The bar shows with or without the toolbar. The choice lasts until another presentation is opened and is not stored.
- The File > Options > Trust Center option "Allow external content" is now off by default.

## Migration

- To keep downloading linked content without asking, pass `allowExternalContent: true` (the equivalent of PowerPoint's "Unblock automatic download of linked images" policy). To block it without showing the bar, pass `allowExternalContent: false`.
- Readers who want automatic downloads can turn on File > Options > Trust Center > "Allow external content".

## Added

- `ooxml-core`: the PowerPoint load result has `hasLinkedWebContent`, true when pictures or media in the deck link to a web address.
- `ooxml-ui`: `<office-ui-message-bar>`, the Office message bar, and `<pptx-ui-external-content-bar>`, PowerPoint's security bar for linked content, translated into every viewer language. `resolveAllowExternalContent` takes the presentation's Enable Content choice, and `externalContentBarVisible` and `dispatchExternalContentBarIntent` drive the bar in every binding.

- Building blocks in every binding expose the security bar the same way: `externalContent` (`{ barVisible, enable, close }`, the `ViewerExternalContentBar` type from `ooxml-ui/pptx`) and the binding's `ExternalContentBar` component (`ExternalContentBarComponent` in `pptx-angular-viewer`, `mountExternalContentBar` in `pptx-vanilla-viewer`). The building-blocks canvas does not draw the bar; the host shell renders it.
- `ooxml-ui`: `prepareExternalContentReload`, the one Enable Content reload every binding makes.

## Security

- Opening a presentation no longer tells the servers it links to that it was opened, or the reader's IP address, until the reader chooses Enable Content.
