## Changed

- `ooxml-core`: `diffOpcPackages` now applies the default package limits (100 MiB of input and of inflated content, 10,000 parts) and rejects a larger package. The OneDrive conflict details in the suite then say the details are unavailable.
- `ooxml-core`, `ooxml-mcp` and the Word, Excel, PowerPoint and Visio MCP packages: file tools refuse path segments that contain `:`, `<`, `>`, `"`, `|`, `?` or `*`, that end in a dot or a space, or that are Windows device names such as `NUL` or `COM1`, on every platform. Paths relative to the root and absolute paths inside it keep working.

## Added

- `ooxml-core/pptx/signature-node`: `inspectPptxDigitalSignatures(data, { checkRevocation: false })` makes no network request and reports the revocation status as `not-checked`.
- `ooxml-core/chart`: `MAX_HISTOGRAM_BINS` and `histogramBinsLimited`, and `chartExSummary` sets `histogramBinsLimited` when a histogram asks for more bins than are drawn.
- `ooxml-core/opc`: `ZipLimits.createOpenError` chooses the error for input that is not a readable zip.

## Fixed

- `ooxml-core`: histogram binning runs in linear time for charts with underflow or overflow bins.

## Security

- `ooxml-core`: every package is now opened through the guarded zip reader, including signature listing, package comparison, Visio collaboration snapshots and embedded chart workbooks, so a small file can no longer inflate without limit. Signature listing also ignores a package whose signature part is larger than 16 MiB. A repository check keeps new code on this path.
- `ooxml-core`: a ChartEx histogram draws at most 1,000 bins, whatever bin count or bin size the file asks for. Before, a chart of a few hundred bytes could exhaust memory.
- `ooxml-core`: the fast XML reader no longer treats names such as `constructor` as known entities or namespace prefixes.
- `ooxml-core`, `ooxml-mcp` and the MCP packages: paths are refused on their text before any filesystem call, so a UNC path no longer reaches a remote host, refused paths all return one error, and an alternate data stream name can no longer create a file past the extension check.
- `ooxml-core/pptx/signature-node`: OCSP requests go only to globally routable addresses, and the connection is made to the address that was checked, so a host name cannot change its answer between the check and the request.
