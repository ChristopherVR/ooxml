## Changed

- No published package changes. The repository's CI now treats a release version bump as no change, so the first push after a release no longer re-runs every check, and its caches survive release bumps. Package contents and the checks a change must pass are unchanged.
- `ooxml-ui`: the Excel editor no longer loads the whole `ooxml-ui` root entry (and with it the Teams app and the other products' editors) to define its dialogs, icons and SmartArt frames. Behaviour is unchanged.
- Repository CI decides which viewers a shared core or `ooxml-ui` change runs from the import graph of the change, and which a dependency update runs from the workspaces that install it. It never runs less than a change can reach, and now also runs viewers the old rules missed, such as Teams for a Word core change.

## Fixed

- A first `bun install` of the repository on Linux, with an empty cache, no longer aborts inside Bun. Contributors and CI runs on a cold cache install normally.
