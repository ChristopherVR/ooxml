## Added

- `ooxml-core/embedding`, `ooxml-ui`, Word viewers, Excel viewers and Visio viewers: `customization.ribbon.hiddenTabs` hides native ribbon tabs in the Word, Excel and Visio editors, with typed ids per product (`WordRibbonTabId`, `ExcelRibbonTabId`, `VisioRibbonTabId`). `'file'` removes the File tab and its backstage at every width, together with its key tip and every other route into the backstage, while Save, Ctrl+S, host `storage` and the `file-command` event keep working. Hiding File while the backstage is open closes it and returns focus to the ribbon, and leaving the option out keeps the current chrome. Every framework binding forwards it with the rest of `customization`.
